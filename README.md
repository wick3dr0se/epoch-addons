# epoch-addons

My Project Epoch (3.3.5 pserver) addons

Most will work with across WotLK but may be configured towards Epoch specifics (and how vanilla + TBC talents affects things).

## Addons

| Addon | Type | Description |
|-------|------|-------------|
| [ElvUI Epoch Seal Twist](ElvUI_EpochSealTwist/) | ElvUI plugin | Retribution Paladin seal-twisting helper. Highlights the twist window on your swing bar and shows which seal to cast next. |
| [ElvUI Damage Meter](ElvUI_DamageMeter/) | ElvUI plugin | Minimal damage meter. Tracks damage per spell with DPS, hit count, and averages. |

## Install

Download the addon folder(s) you want and drop them into your WoW `Interface/AddOns/` directory.

```
Wow/
  Interface/
    AddOns/
      ElvUI_EpochSealTwist/
        EpochSealTwist.toc
        EpochSealTwist.lua
        (README.md)
```
